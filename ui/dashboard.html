Retained activity

Counts cover observed retained events. Tool completion does not imply success. Empty counts do not establish that hooks are connected. Scope follows the native session directory, not a shell call's workdir.

Project files

Only the configured project is read. Ignored paths, links and secret filenames are excluded.

Working-tree changes

Git changes against HEAD can include concurrent human edits. This view is read-only; it does not attribute changes to a specific turn or restore files.

Selected Git checkpoints

Only the two commits selected in reviewed settings are compared. They may include human edits or multiple turns. Inspection never changes files, creates commits or restores edits.

Access and usage

No network or additional model calls. Hooks and the local service run with local process permissions, distinct from the model tool sandbox.

Hooks supply no token or context counters. An explicitly selected private export can supply a reported completion snapshot, which may include earlier thread usage. Context occupancy, cache health and exact billing remain unavailable. Missing data is not zero. There are no paid keepalive calls.

Local preview

Paste up to 4,096 characters. This panel renders locally without sending the source to tools, a model or the network. It makes no file writes or persistent storage; source remains in panel memory until cleared or closed. The host controls its webview.

Original restricted renderer, not the Mermaid library. One statement per line: flowchart TD/TB/LR/RL/BT, bare node, A["label"] or A --> B. At most 16 nodes, 24 edges and 64 lines. No HTML, directives, links, styling, subgraphs, other shapes or automatic layout. Labels are literal table text.

Development checkpoint. A dashboard button never approves a pending native tool call. Configure access through a reviewed runtime settings file; installation and changed-hook trust remain separate steps.
