# Skills and observable workflows

These five bundled skills use the model selected for the current chat and consume
usage. They are model-mediated instructions, not immediate native slash callbacks.
Their local CLI operations do not initiate another model run. The skills grant no
new installation, network, trust, approval, logging or model-routing authority.

| Skill | When to use it | Scoped access and output | Concrete acceptance |
| --- | --- | --- | --- |
| manage-claude-mods | Inspect/configure/validate/replay/report on the framework | Verify the installed package root; read its guide/config and explicitly selected settings/data. Write only requested config changes; reports return counts. | Verified absolute CLI, unrelated entries preserved, default logging unchanged, exact replacements disclosed, native trust human-controlled. |
| mod-scaffolding | Describe a notice, lexical denial or exact Bash replacement | Read the reviewed specification and package; write a new explicitly selected output directory. No generated executable or automatic install. | Disabled config validates; matching/control fixtures both abstain disabled. A separate temporary enabled copy produces only the intended notice/deny/replacement; control abstains. |
| systematic-debugging | A reproducible hook/transport/state/UI fault | Read selected source/config and synthetic diagnostics. Reproduce at the failing boundary, then make the smallest authorized fix. | Before/after evidence separates config, dispatcher and native host. No speculative trust/permission bypass or private-session search. |
| verify-mod-completion | A claimed milestone or completion | Read requirements/change and run relevant authorized tests. Save a scoped verification record when requested. | Unit/OS/subprocess/native evidence stay distinct; missing host checks remain incomplete. No full-product declaration from a partial pass. |
| prepare-mod-review | Review source or generated data before use | Inspect the selected diff, access delta, package and relevant test results. Produce reviewer notes. | Explain behavior, processes/roots/network/retention/model usage, exact observed tests and remaining limits. No implied publish/install authority. |

## Source dev8 authoring improvement

Scaffold output adds fixtures/matching.json and fixtures/nonmatching.json beside
the disabled mods.json, access.json and REVIEW.md. A notice's control is a tool
event; command-rule controls use the same Bash tool and a different command chosen
to avoid a lexical/exact collision. The CLI regression includes overlapping
control text and a fixture that would write a marker if executed; replay creates
no marker. Never execute fixture commands. They contain the selected match/from
text as plaintext and need the same review/privacy scope as the specification.

The access declaration describes the runtime template, not the authoring process:
scaffolding writes its listed files. It does not sandbox edited code or attest
source authenticity. Source8 is not installed; immutable installed dev6 still has
the older three-file scaffold output. Check the actual package/version/output.
See [authoring](authoring.md) for the disabled and temporary-enabled workflow.

## Selected-chat application observed — 2026-10-23

On human-selected Sol Medium, the installed dev6 skill files were read and their
workflow applied in the existing chat. Its absolute CLI scaffolded a disposable
synthetic deny configuration. Disabled replay abstained. An enabled temporary copy
also abstained unexpectedly: its selected literal had a hyphen while the synthetic
command had an underscore. Inspection of the literal matcher explained the result.
Changing only that temporary literal produced denial for the matching event and
abstention for the control. The original generated config remained disabled and
byte-identical. Access review found no runtime writes/network/model calls.

This is a synthetic configuration diagnosis, not a product/runtime bug or native
hook-delivery proof. Review recorded only selected disposable authoring writes,
no installation/trust/logging change, and the native checks still missing. No
independent evaluator, new model/API run, prompt rewrite or automatic approval was
used. It demonstrates current-chat application of the skills, not general quality
certification for every natural-language request or host.

Source dev8's real CLI regression separately covers all three scaffold templates,
control collisions, disabled and temporary-enabled replay, preservation of the
disabled original and no command execution. Static YAML/frontmatter validation is
separate from workflow behavior; neither establishes native discovery or trust.
