## First useful proof of concept

Feed a documented `PreToolUse` fixture to a local configured guard. Show that a matching action produces the exact native denial envelope, a nonmatch yields no permission decision, and a later mod cannot overturn a denial. No Codex login, model call, installation, or trust bypass is needed. This proves our adapter contract, not installed-host execution.

## Build order

1. Implement strict configuration/event/result validation and a bounded dispatcher. Include three fixture types for the supported events. Add the guard proof before wider features.
2. Add `validate`, `replay`, and `report` commands with useful help, predictable exit status, and stdout/stderr separation. Replay must say it executes configured local code but never execute the tool command contained in a fixture.

4. Package as a local source-only plugin. Include a focused skill, example configuration, and an authoring/conversion guide. No installer should edit user configuration, trust hooks, install system software, or contact a service.

## Required checks

Use Node's built-in test runner if sufficient. Cover behavior that can fail at the integration boundary:

- Valid native envelopes and exact denial shape; malformed JSON, wrong event, missing/wrong-type fields, oversized input, unsupported outputs.
- Nonmatch produces no approval; denial survives subsequent mods; disabled modules are not executed.
- Errors and invalid mod output have explicit outcomes; input, matching loops, journal work, and host hook duration are bounded. Diagnostics do not corrupt protocol stdout. No arbitrary user-defined handler is loaded in v0.1.
- Rejection of executable-path or expression configuration, unsafe record identifiers, journal concurrency, symlinks, and unavailable/unwritable data directories.
- Journal and report contain only allowed metadata, never fixture secrets, prompts, commands, tool results, or transcript paths.
- CLI exit codes/help and a complete fixture replay/report journey from a clean package path containing spaces.
- Package paths exist, manifest JSON is valid, hook commands quote paths, and the archive excludes logs, credentials, generated investigation artifacts, dependencies, and private paths.

Compare output fixtures against the pinned public hook schemas and add semantic restrictions beyond those schemas. The schemas accept some fields that current runtime behavior rejects. Record the source commit used; do not silently claim the latest source schema is generated by the installed CLI.
